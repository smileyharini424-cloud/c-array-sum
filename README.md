# Sum of Array Elements

## Explanation

This C program calculates the sum of all elements present in an integer array.

## Problem Statement

Given an array of integers, find the sum of all elements in the array.

## Features

- Accepts array elements from the user
- Calculates the total sum
- Uses array traversal
- Simple and beginner-friendly

## How It Works

The program reads the array elements one by one and adds each element to the sum variable.

## Technologies Used

- C
- Standard Input and Output

## Data Structure Used

- Array

## Methods Used

- Array traversal
- Addition
- for loop

## Program Flow

1. Read the number of elements.
2. Read the array elements.
3. Add each element to the sum.
4. Display the total sum.

## Sample Input

5
10 20 30 40 50

## Sample Output

Sum of array elements = 150

## Time Complexity

O(n)

## Space Complexity

O(n)

## Key Learning

Learned how to traverse an array and calculate the sum of its elements.
